# Patchwork

## Register

product

## Users

Developers who use specifications and coding agents, then review the resulting Git changes on Windows and macOS. Their primary task is to inspect changes, understand context and send concrete feedback to the agent.

## Product Purpose

A lightweight local desktop workspace for reviewing code, comparing working trees with branches, reading whole files, leaving review comments, and staging or committing changes. Agents can open the exact review context through MCP.

## Brand Personality

Focused, precise, familiar. The user explicitly chose VS Code as the interface reference, a console-like experience, configurable themes and keyboard access.

## Anti-references

Decorative dashboards, spacious marketing layouts, excessive animation and chrome that competes with source code.

## Design Principles

- Code gets the largest part of the workspace.
- Context and changes are one keystroke apart.
- Use familiar editor affordances, predictable navigation and visible Git state.
- Connect agents with copyable configuration and concrete review feedback.
- Never hide errors behind successful-looking UI.

## Accessibility & Inclusion

Keyboard navigation, visible focus, reduced motion, readable contrast, labels in addition to change colors, configurable type size, dark and light themes.
